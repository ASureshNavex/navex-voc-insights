# Prototype

`voc-insights-workspace-latest.html` is the latest workspace prototype (19 November 2026) in the NAVEX style. Open it in a browser. It is the reference for screen content, labels, fields and navigation.

- All accounts, people and figures are fictional sample data.
- The role and persona selectors in the top bar, and the role field on the sign-in card, exist only to demonstrate each role. The product does not have them: identity, role and scope come from SSO.
- In the product, notifications open from the bell icon in the top bar.
- It is a single file of plain HTML, CSS and JavaScript. Do not copy its code into the React app; rebuild each screen with the components and rules in `docs/03-engineering/coding-standards.md`.
