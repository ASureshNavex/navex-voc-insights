# Glossary

| Term | Meaning |
|---|---|
| Account | A NAVEX customer, keyed by its Salesforce account ID across Snowflake, Enterpret and Gainsight |
| AE | Account Executive, the sales owner of an account |
| ARR | Annual recurring revenue of an account |
| ARR at risk | ARR of accounts rated Red or Yellow |
| ARR tier | Filter bucket: $50K and above, or below $50K |
| Churn language | Feedback in which the customer talks about leaving. Flags the account ahead of ARR in the default sort |
| Churn score | A model estimate, 0 to 100, of how likely an account is to churn, from usage, support and contract signals. Not built from VoC feedback. Shown beside the VoC rating, never blended with it |
| CTA | Call to action in Gainsight. The VoC CTA links into the workspace |
| CXM | Customer Experience Manager, the owner of an account's customer relationship |
| Data scope | The set of accounts a user may see: `OWN_BOOK`, `TEAM`, `REGION` or `ALL` |
| Digest | A scheduled email summary for an audience |
| Enterpret | The feedback analytics platform that classifies NAVEX feedback into a three-level taxonomy |
| Exec sponsor | The NAVEX executive assigned to an account |
| Friction | Difficulty a customer reports with NAVEX products or service |
| Friction score | 0 to 100 score per account per week; higher means more friction |
| Issue status | Whether a flagged account has an open product issue: Red with open issue, Red with no open issue, Churn language with no issue, No flag |
| Knowledge hub | Governed store of research files such as interview and Customer Advisory Board notes |
| New red | Red this week and not red last week |
| New yellow | Yellow this week and green last week |
| NPS | Net Promoter Score category for the account (Promoter, Passive, Detractor) with its date |
| Published run | The refresh run whose results users currently see |
| Rating | The VoC rating of an account: Red, Yellow or Green |
| Repeat red | Red this week and last week |
| Rule or trigger | The code and text of the rule that explains the current rating, for example AR1 New red this week |
| Scorecard | The one view: rating cards, segment cards, week over week, filters and the accounts table |
| Super product family | Top-level NAVEX product grouping, for example NAVEX One, Incident Management, Policy Management |
| T-180 | 180 days before renewal, when renewal workflows start |
| Taxonomy | Enterpret's three-level classification of feedback. Themes are shown straight from it |
| Theme | A taxonomy entry attached to an account's feedback |
| Verbatim | A masked excerpt of what a customer said, with source and date |
| VoC | Voice of the Customer |
| VoC sentiment | Tone of the customer's feedback this period, read from Enterpret: Positive, Neutral or Negative |
| Weekly snapshot | The status of every account at the weekly cut-off, used for week-over-week comparison |
