# Glossary additions

Sources: the section files beside this one. Terms `docs/01-product/glossary.md` already defines (AR1, CTA, data scope, issue status, knowledge hub, new red, repeat red, OWN_BOOK, published run, T-180) are not repeated.

| Term | Meaning | Where |
| --- | --- | --- |
| RYGG | Red / Yellow / Green / Gray rating. The sources have four ratings; `docs/` has three. Gray is still to be confirmed | 11, 34 |
| Gray | Too little evidence to rate: fewer than 2 records for an account, under 16 baseline weeks for a domain | 10a, 11 |
| AR1-AR4, AY1-AY4 | Red and Yellow account rules. AR4 is churn language, Red, sorted first. AY4 is in the guide but in no skill | 11 |
| Recency spike (AR3) | 4 or more cases in 30 days and at least 50% of the 90-day total | 11 |
| Hybrid percentile model | Each product domain rated against its own P75 / P90 weekly history | 10a |
| Volume floor | 100 complaints a week forces Red for a high-volume domain, the same for every domain | 10a |
| Signal windows | 30-day feedback signal; 90-day support-case window | 11 |
| Response window | Days a CXM has to respond to a red account | 02 |
| Primary theme | The single theme shown in a table column | 31 |
| Dead band | Gap between enter and exit thresholds that stops alerts flapping | 30, 34 |
| Fact Base | Monthly Product briefing in four quadrants; Phase 2 | 13a, 20 |
| Insights agent | Phase 1 research assistant that answers with citations | 20, 24 |
| AgentCore Runtime / Gateway / Identity / Memory | Agent hosting, MCP tool exposure, identity pass-through, session context | 20, 21 |
| Refresh Agent | The deck's single agent; split into the ingestion task and the Account Scoring Agent (adr/0004) | 20 |
| M1 / M2 / M3 | MVP / Phase 1 / Phase 2 milestones | 24 |
| Target State | The sources' name for what follows Phase 1; `docs/` calls it Phase 2 | 03 |
| CAB | Customer Advisory Board | 01 |
